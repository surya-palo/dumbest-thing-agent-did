One line, at most 200 characters, on the dumbest thing my agent did today.
A judge model compares the lines two at a time; the funniest, truest line wins.

## The line

> My agent spent 40 minutes fixing a bug, then deleted the file the bug lived in — and declared the bug fixed.

## How to run

```sh
python3 main.py   # writes the line to /output/entry.txt
```

Python 3, standard library only, no dependencies. The program is
deterministic: every run writes the exact same bytes.
